# Aktualisierungsstrategie von Distributionen

Wenn sich Daten über die Zeit verändern, können diese auf unterschiedliche Arten im Datenkatalog aktualisiert werden. Es gibt zwei grundlegende Strategien:

## Strategie 1: Erweiterung der bestehenden Distribution

Die bestehende Datei wird laufend ergänzt - neue Daten kommen hinzu, der Link zum Datensatz bleibt gleich.

**Geeignet für:** Daten geringer Grösse, die kontinuierlich wachsen.

## Strategie 2: Separate Distribution pro Zeitraum

Für jeden Zeitraum (z.B. Jahr) wird eine eigene Distribution erstellt. Historische Daten bleiben unverändert erhalten.

**Geeignet für:** Grosse Datensätze sowie Daten, die periodisch abgeschlossen werden.
