# Datensätze organisieren

## Datensätze fassen
Unser Metadatenstandard DCAT AP CH hat ein mehrstufiges Metadatenmodell: In einem **Datensatz** können mehrere **Distributionen** liegen, wie in einem Mäppli mehrere Dokumente liegen können.

Wir nutzen das, um Datensätze zusammenfassen zu können und so mehr Überblick in die grosse Datenmenge des Kantons zu bringen. Datensätze werden thematisch gefasst und sind noch nicht auf ein Datenprodukt zugeschnitten - der Datensatz entspricht einem grossen Sack Rüebli (vgl. [Produktsicht auf Daten](/ogd-handbook/ogd_grundlagen/ogd-in-kuerze#produktsicht-auf-daten)). Einzelne Distributionen im Datensatz können verschiedene Aspekte der Daten darstellen oder auf verschiedene Zwecke zugeschnitten sein.

Die meisten Metadaten liegen auf dem Datensatz selbst, z.B. die datenhaltende Stelle, der Kontakt für Fragen und der Zeitraum, auf den sich die Daten in den Distributionen beziehen. Daten können zu einem Datensatz zusammengefasst werden, wenn sich die Metadaten nicht widersprechen.

:::info
Daten lassen sich für mehr Überblick zusammenfassen, wenn
- sie eine thematische Einheit bilden
- denselben Zeitraum umfassen oder gemeinsam eine Zeitreihe ergeben
- denselben Entstehungszusammenhang haben
:::


## Aktualisierungsstrategie von Distributionen

Wenn sich Daten über die Zeit verändern, können diese auf unterschiedliche Arten im Datenkatalog aktualisiert werden. Es gibt zwei grundlegende Strategien:

### Strategie 1: Erweiterung der bestehenden Distribution

Die bestehende Datei wird laufend ergänzt - neue Daten kommen hinzu, der Link zum Datensatz bleibt gleich. <br /> **Geeignet für:** Daten geringer Grösse, die kontinuierlich wachsen.

### Strategie 2: Separate Distribution pro Zeitraum

Für jeden Zeitraum (z.B. Jahr) wird eine eigene Distribution erstellt. Historische Daten bleiben unverändert erhalten. <br /> **Geeignet für:** Grosse Datensätze sowie Daten, die periodisch abgeschlossen werden.
