# Offene Daten visualisieren

Offene Daten bilden die Grundlage für Datenprodukte wie Visualisierungen, die Informationen einem breiten Publikum zugänglich machen. Wer Daten als OGD publiziert, schafft damit die Voraussetzung für solche Anwendungen.

Die folgenden Beispiele laden die Daten direkt aus dem Datenkatalog. Das vereinfacht die Pflege und Aktualisierung der Visualisierungen, da die Daten nur an einer zentralen Stelle verwaltet werden müssen.

:::info Visualisierungslibrary des Statistischen Amts
Das Statistische Amt entwickelt derzeit eine Visualisierungslibrary, mit der sich Daten einfach visualisieren und auf der Website des Kantons veröffentlichen lassen. Sobald die Library verfügbar ist, wird sie in diesem Handbuch verlinkt.
:::

---

## Beispiele Daten-Visualisierung

<CardGrid cols={2}>

<Card title="Visualisierung: Bevölkerung" href="https://www.zh.ch/de/soziales/bevoelkerungszahlen/bestand-struktur.html">

<img src="/ogd-handbook/img/datavis_bevölkerung.png" alt="Screenshot Bevölkerungsvisualisierung auf zh.ch" style={{width: '100%', borderRadius: '4px', marginBottom: '0.75rem'}} />

Die Entwicklung der Bevölkerung wird mit einem Flächendiagramm dargestellt. Ergänzend veranschaulicht eine Bevölkerungspyramide die Alters- und Geschlechtsstruktur sowie die Staatsangehörigkeit der Bevölkerung. Mithilfe von Interaktionselementen können die Daten gefiltert und die Darstellung angepasst werden.
<br />
**OGD-Grundlage:** <a href="https://datenkatalog.statistik.zh.ch/datasets/254@statistisches-amt-kanton-zuerich">Bevölkerung</a>,
<a href="https://datenkatalog.statistik.zh.ch/datasets/127@statistisches-amt-kanton-zuerich">Bevölkerungsbestand</a>

</Card>

<Card title="Visualisierung: Leerwohnungen" href="https://www.zh.ch/de/planen-bauen/raumplanung/immobilienmarkt/leerwohnungen.html">

<br />
**OGD-Grundlage:** <a href="https://datenkatalog.statistik.zh.ch/datasets/110@statistisches-amt-kanton-zuerich">Leerwohnungsquote</a>
